# Equa Frontend

Mobile-first React web app shell (Vite + React 18 + TypeScript + Tailwind).

## Scripts

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run test
npm run preview
```

## Structure

- `src/layouts/` — AppShell (mobile bottom nav, desktop sidebar)
- `src/pages/` — Chat placeholder, 404
- `src/components/` — BrandLogo, BottomNav
- `src/shared/` — reserved for API client / UI (F4+)

PWA, mock API, and streaming chat come in later frontend tasks (F3–F8).
